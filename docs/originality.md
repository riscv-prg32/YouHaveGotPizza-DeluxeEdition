# Originality and provenance

This file records where each asset comes from. It is a record of good-faith process and **not a legal
opinion**. No formal clearance search has been done.

## Provenance

| Asset | Source |
|---|---|
| Sprites, font | Drawn as text for this game, in `tools/art_sprites.py` |
| Scenes | Generated by original code in `tools/art_scenes.py` |
| Levels | Designed for this game, in `tools/levels.py` |
| Music | Composed for this game, in `tools/build_audio.py` |
| Sound effects | Short original note scripts on the PRG32 synthesizer |
| Code | Written for this game. Build and validation scripts are adapted from sibling MIT-licensed PRG32 projects, and say so in their headers |

No samples, recordings, fonts, images or code from outside the PRG32 family are included. Nothing from
the original demonstrator's art or music was reused: only its premise, its title and its characters'
roles, from the same project and owner.

## The inspiration, and the boundary

The genre goes back to the arcade game *BurgerTime* (Data East, 1982), named here only to acknowledge
history. The original demonstrator was openly inspired by it. Game *mechanics* of this general kind are
widely reused across the medium. This game keeps to the following boundaries:

| Element | This game |
|---|---|
| Name and branding | Its own. The Store metadata does not use the older game's name |
| Theme | A university and pizza, with a professor and students, set in Naples |
| Characters | Original, with no food-shaped opponents and no chef-versus-food story |
| Weapon | A flour cloud, with its own rules |
| Layouts | Original, with 40 x 25 tile geometry and a mechanical reachability check, not copied |
| Music | No melody from any game. Nothing was transcribed |

## Real places and traditions

Place names (Pignasecca, the Lungomare) and generic subjects (a volcano on a bay, a wood oven, a street
shrine) are used descriptively, with no real building reproduced. The "6/8 dance" style draws on a
traditional idiom. No traditional melody is quoted, but the melodies are short, use common harmony and
were checked by their composition process only, **not** against a corpus of existing music. A short
phrase coincidentally resembling something else cannot be excluded.
